    학생 기록 붙여 넣기

    학급 게시판(클래스룸 댓글 등)에 모인 학생 기록을 그대로 복사해 붙여 넣으세요. 아래 세 가지를 자동으로 알아봅니다. 같은 기록은 한 번만 들어가요.

    알아보는 형식

    ⟦질문⟧ 이름 | 유형 | 질문 | 사다리 | 앱 ← 질문 분류 카드(2)·사다리 코치(3)·아테네 시민(5) 성찰: 시민이 '언제나'를 쓴 걸 물었을 때 … ← 아테네 시민 성찰 (바로 위 학생에게 붙음) 이름: 건우 초점: 거짓말은 나쁘다 … 1. 착한 거짓말은 누가 정할까? ← 질문 폭풍(1) 목록

    투표판(4)·서클 보드(6)·워크시트(7)는 이 기기에서 쓴 기록을 자동으로 읽습니다. 학생 이름은 서클 보드의 명단과 같게 써야 한 사람으로 합쳐집니다.

    들어와 있는 자료

    모든 기록은 이 브라우저에만 저장되고 밖으로 보내지 않습니다. 학기 말에는 CSV로 내려받아 보관한 뒤 지우세요.

    점검지 점수 입력

    한 줄에 한 학생. 이름 뒤에 12문항 점수(1~4)를 띄어 쓰거나 붙여 쓰세요. 예: 건우 3 3 2 4 3 2 3 3 2 3 4 3 또는 건우 332432332343
