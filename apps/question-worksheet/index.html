질문 만들기 워크시트

좋은 서·논술형 질문은 발문 + 자료 + 조건, 그리고 채점기준으로 이루어져요. 5단계를 차례로 채우면 나만의 질문이 완성됩니다. 도우미 문장을 눌러 발문에 넣어 보세요.

1

무엇을 물을까?

이번 시간에 배운 것 중에서, 친구가 생각해서 답해야 할 주제를 하나 고르세요.

배운 개념·주제
2

자료 고르기

답의 근거가 될 자료(글·그림·표·사진)를 정해요. 자료 없이 풀 수 있으면 좋은 질문이 아니에요.

자료 붙이기 / 자료 설명
3
