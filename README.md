# 소크라테스 포털

소크라테스식 질문 7차시 수업(초등 5~6학년)의 웹 앱 7종을 한 페이지에서 여는 포털입니다.

| 차시 | 앱 | 사용자 |
|---|---|---|
| 1 | 질문 폭풍 — 질문 쏟아내기(QFT) | 학생 |
| 2 | 질문 분류 카드 — 닫힌·열린, 6가지 질문 | 학생 |
| 3 | 질문 사다리 코치 — 1층→3층 고쳐 쓰기 | 학생 |
| 4 | 질문 투표판 — 펼치기·합치기·투표(P4C) | 교사 화면 |
| 5 | 아테네 시민 챌린지 — 과잉확신·확증편향 검증 | 학생 |
| 6 | 소크라테스 서클 보드 — 피시볼 토론 기록 | 교사 화면 |
| 7 | 질문 만들기 워크시트 — 서·논술형 문항으로 | 학생 |
| 기록 | 질문 성장 리포트 — 7개 앱 기록 모음, 학급 통계, 학생별 피드백·학생부 초안 | 교사 |

- 질문 사다리: 1층 사실 확인 · 2층 연결·설명 · 3층 전이·주장
- 모든 앱은 단일 HTML이며 서버·AI·학생 계정 없이 동작합니다.
- 학생 기록은 각 브라우저의 localStorage에만 저장되고 외부로 전송되지 않습니다.
- 앱 사이 연결은 `⟦질문⟧ 이름 | 유형 | 질문 | 사다리` 한 줄 형식과, 같은 주소에서 열 때 공유되는 브라우저 저장소로 이뤄집니다.
- 코치 링크 끝에 `#nohint`를 붙이면 말머리 힌트를 숨깁니다.
